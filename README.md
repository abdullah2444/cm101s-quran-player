# CM101s-2 Linux Quran Player, Prayer Display & Hardware Video Output

Turn an old **China Mobile CM101s-2** TV box (**HiSilicon Hi3798MV100**, ARMv7, 1 GB RAM, 8 GB eMMC) running **HiNAS / Ubuntu 20.04 (Linux kernel 4.4.35)** into a dedicated HDMI + AUX Quran player with:

- **2-page Madani Mushaf display** on HDMI (`1920x1080` via `/dev/fb0` `hifb`) with **real-time word/verse highlighting** synced to Mishary Alafasy recitation (`mpg123 -R`)
- **Offline daily prayer times** (Muslim World League, configurable latitude/longitude/timezone), countdowns, and a remote-controlled **"Prayed" reminder mark**
- **AUX audio playback + anti-hiss silence keeper** (`aplay /dev/zero` whenever idle) and **logarithmic dB volume control** (since the `HISI-AIAO` hardware mixer ignores writes)
- **Full NEC IR remote control** via `/dev/hi_ir` + **real suspend-to-RAM standby** via `/dev/hi_pm` (power MCU wakes on the red power button without rebooting)
- **Web remote control UI** (`quran.php`, `videos.php`, `airplay.php`, `home.php`)
- **Hardware-accelerated H.264/H.265 video playback (`vplay`) & iPhone AirPlay mirroring (`uxplay` + GStreamer sink)** running directly on the HiSilicon video layer underneath the transparent `/dev/fb0` UI

> **Installing Linux first:** See [`docs/INSTALLING_LINUX.md`](docs/INSTALLING_LINUX.md) for flashing **HiNAS / Ubuntu 20.04** onto a stock Android CM101s-2 (UART pins, full eMMC backup, `mdmo1g` DDR bootloader note, `emmc.flash` layout, and MD5-verified flash).
>
> **How Linux video & HDMI output was solved:** See [`docs/LINUX_VIDEO_OUTPUT.md`](docs/LINUX_VIDEO_OUTPUT.md) for the complete write-up (framebuffer quirks, reconstructing `libhimini.so` when the kernel has no userspace libraries, fixing 25/60 fps A/V sync, and raw NV21 frame capture).

## Turning the TV Box into a Quran Player

### 1. System Prerequisites (on the HiNAS / Ubuntu 20.04 box)

```bash
apt update
apt install -y python3-pil mpg123 alsa-utils fonts-dejavu
```

### 2. Prepare Quran Audio, Mushaf Pages & Verse Timings

`quran-player.py` expects `/home/ubuntu/quran`:

- `/home/ubuntu/quran/audio/001.mp3` ... `114.mp3` (Mishary Alafasy QDC files matching `api.quran.com` recitation ID `7`)
- `/home/ubuntu/quran/pages/001.png` ... `604.png` (grayscale ink masks generated by `quran-tv/prep_quran.py` / `prep_1260.py` from `width_1024` / `width_1260` Mushaf PNGs + `ayahinfo` SQLite DB)
- `/home/ubuntu/quran/quran.json` (surah metadata, `verse_page`, per-page verse bounding boxes, and millisecond verse timings)

Run `prep_quran.py` (adjust `SRC` inside the script to match your local asset directory) and copy the generated `box/` output to `/home/ubuntu/quran/`.

### 3. Configure Prayer Location

Copy `quran-tv/prayer-location.json.example` to `/etc/prayer-location.json` and edit your coordinates, timezone offset, and display label:

```json
{
  "lat": 21.4225,
  "lng": 39.8262,
  "tz": 3,
  "city": "Makkah"
}
```

### 4. Install Services & Scripts

```bash
install -m 755 quran-tv/quran-player.py /usr/local/bin/quran-player.py
install -m 755 quran-tv/hdmi-status.py /usr/local/bin/hdmi-status.py
install -m 755 quran-tv/box-standby.py /usr/local/bin/box-standby.py

cp quran-tv/systemd/quran-player.service /etc/systemd/system/
cp quran-tv/systemd/hdmi-status.service /etc/systemd/system/
mkdir -p /etc/systemd/system/hdmi-status.service.d
cp quran-tv/systemd/hdmi-status.boot-delay.conf /etc/systemd/system/hdmi-status.service.d/boot-delay.conf

systemctl daemon-reload
systemctl enable --now quran-player hdmi-status
```

> **Why the 60s boot delay drop-in?** The stock bootloader/HiNAS init redraws the splash logo during early boot and covers `/dev/fb0`. Waiting until `/proc/uptime >= 60s` keeps `hdmi-status` cleanly on top.
>
> **Native Rust binaries:** Ready-to-cross-compile Rust ports of `quran-player`, `hdmi-status`, `box-standby`, and `audio-control` live in [`rust/`](rust/README.md) (`cargo zigbuild --release --target armv7-unknown-linux-gnueabihf.2.31`) if you prefer standalone ARMv7 ELF binaries over Python.

### 5. Web Interface (Optional)

Copy `quran-tv/web/*.php` into `/var/www/html/` (preserving your existing `require_login.php` session/CSRF wrapper). Notice:

- `quran.php`: Surah/Verse picker, transport controls, volume slider (0–99 dB scale), repeat mode
- `videos.php`: Browse `VIDEO_ROOT` (defaults to `/mnt/media`, override via `VIDEO_ROOT=...`) and play H.264/H.265 files with `vplay`
- `airplay.php`: Start/stop `uxplay` screen mirroring (if built with `linux-video/airplay/uxplay.patch`)

## IR Remote Keymap (`/dev/hi_ir`)

NEC codes are mapped in `KEYS` inside `quran-tv/quran-player.py` (56-byte `/dev/hi_ir` structs read non-blocking via `select()`, bytes `8:12` keycode, byte `48` `0=down / 1=hold / 2=up`):

| Key | On Home Screen | On Quran Screen | In Video Player / Chooser |
|---|---|---|---|
| **Green** | Open Quran screen (resumes) | Play / Pause | Open / Play |
| **OK** | Play / Pause audio | Play / Pause (or confirm digits) | Pause / Resume (or select) |
| **Up / Down** | — | Previous / Next Surah | Prev / Next episode (or move) |
| **Left / Right** | — | Previous / Next Verse | ±10 s seek (or page 8 items) |
| **0–9 / Del** | — | Type Surah number + OK | — |
| **Back / Home** | — | Hide Quran UI (audio continues) | Back to list / Stop |
| **Menu** | Start AirPlay (when idle) | Toggle Repeat (`next` / `surah`) | — |
| **Set** | Open Video chooser | Open Video chooser (stops Quran) | Close chooser |
| **Mouse key** | Acknowledge prayer reminder | Acknowledge prayer reminder | Acknowledge prayer reminder |
| **Power (Alt)** | Toggle Screen Off (audio stays on) | Toggle Screen Off (audio stays on) | Stop |
| **Power (Red)** | Suspend to RAM (`/dev/hi_pm`) | Stop all + Suspend to RAM | Stop all + Suspend to RAM |

## Notes on Audio (`HISI-AIAO`)

- **Software volume only:** `amixer` writes return success on `HISI-AIAO` (`plughw:0,0`) without changing output gain. `quran-player.py` and `vplay` both apply an exponential **0.5 dB/step** curve (`0..99`, `99 = 0 dB`).
- **Idle AUX hiss:** Leaving the PCM device closed causes audible hiss on amplified speakers. `silence_keeper()` streams `/dev/zero` via `aplay` whenever nothing is playing and releases `/proc/asound/card0/pcm0p/sub0/status` cleanly before `mpg123`, `vplay`, or AirPlay claims ALSA.
